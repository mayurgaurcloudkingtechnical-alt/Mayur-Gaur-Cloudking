# SLG SKILLVERSE — Powered by SoftLab Global

**Tagline:** Your World of Future Skills.  
**Supporting Line:** From Class 8 to 12 | School Foundation to IIT-JEE and Beyond  
**Target Subdomain:** `https://skillverse.softlabglobal.com`  
**Local / Path Prefix Access:** `http://localhost:3000/skillverse` or `http://skillverse.localhost:3000`

## Overview
SLG SKILLVERSE is an isolated education venture built inside the SoftLab Global Next.js 14 monorepo without modifying or disrupting the existing corporate website (`www.softlabglobal.com`), LMS (`lms.softlabglobal.com`), or CRM workflows.

## Key Capabilities
1. **31 Public Pages**: Homepage, About, All Courses, 14 Academic/Competitive/Tech Program Pages, Packages & Transparent Fees, Admissions, Free Demo Class, Student Diagnostic Assessment, Contact, FAQs, Blog, 4 Legal/DPDP Policies, and 3 Role Login Portals.
2. **Configurable Catalogue & Fee Engine**:
   - 5 Monthly Academic Packages (`₹1,499/mo` to `₹3,999/mo` with 12-month undiscounted totals).
   - 9 Competitive-Exam Add-Ons (`IIT-JEE`, `NEET-UG`, `Olympiad`, `CUET`, `NDA`, `NTSE-style Aptitude`) never bundled silently.
   - 14 Standalone Technology, AI, Coding & Communication Courses.
   - Initial Fee Rules (`₹500` Admission & Registration, `₹500` Student ID & Learning Kit, `₹0` Free Assessment & Demo).
3. **11-Stage Admissions CRM**:
   - `ENQUIRY` → `FOLLOW_UP` → `DEMO_BOOKING` → `ASSESSMENT` → `COUNSELING` → `APPLICATION` → `PARENT_CONSENT` → `FEE_PAYMENT` → `ENROLLMENT` → `BATCH_ALLOCATION` → `ACTIVE_STUDENT`.
4. **Role-Based Portals**:
   - Student Portal (`/skillverse/student-login`)
   - Family-Isolated Parent Portal (`/skillverse/parent-login`)
   - Teacher & Admin Portal (`/skillverse/staff-login` and `/admin/skillverse`)
   - Public Certificate Verification (`/skillverse/verify/[certificateNumber]`)
