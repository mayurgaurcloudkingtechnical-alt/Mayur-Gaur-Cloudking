# SLG SKILLVERSE — Administrator & Staff Guide

## Accessing the Admin & Staff Portal
- Navigate to `/skillverse/staff-login` (or `https://skillverse.softlabglobal.com/staff-login`) or `/admin/skillverse` while signed into your SoftLab Global staff account.

## Managing Key Workflows
1. **11-Stage Admissions CRM**:
   - View incoming student enquiries with verified parent consent.
   - Advance the stage dropdown from `ENQUIRY` through `DEMO_BOOKING`, `ASSESSMENT`, `COUNSELING`, `APPLICATION`, `PARENT_CONSENT`, `FEE_PAYMENT`, and `ENROLLMENT` / `ACTIVE_STUDENT`.
   - When an enquiry reaches `ENROLLMENT` or `ACTIVE_STUDENT`, the system automatically generates:
     - A Student Enrollment ID (`SV-STU-YYYY-XXX`)
     - A Parent Access PIN (initial default: last 4 digits of registered parent mobile)
     - An itemized Fee Invoice (`SV-INV-YYYY-XXXX`)
2. **Teacher Attendance Desk**:
   - Open **Students, Batches & Teacher Portal** tab -> enter the Student Enrollment Code, Subject, and Status (`PRESENT` / `LATE` / `ABSENT`) -> click **Record Attendance Entry**.
3. **Certificates**:
   - Open **Certificates & Verification** tab -> issue or revoke verifiable certificates (`SLG-SV-CERT-YYYY-XXXX`).
4. **CMS & SEO**:
   - Open **Admin CMS & SEO** tab -> update hero headlines, campus address, phone/WhatsApp, and SEO metadata without code changes.
